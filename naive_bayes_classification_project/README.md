# Naive Bayes Classification Project

## Deskripsi
Proyek ini merupakan rancangan aplikasi klasifikasi berbasis web yang menerapkan algoritma **Naïve Bayes** untuk mengelompokkan data ke dalam kelas yang telah ditentukan.

Struktur proyek mengikuti pola dokumen proyek perangkat lunak pada contoh yang diberikan, meliputi PRD, SRS, user stories, use cases, HLD, LLD, ERD, model data, kontrak API, dan OpenAPI.

## Topik
**Penerapan Algoritma Naïve Bayes untuk Klasifikasi**

## Catatan sumber
PDF jurnal yang diunggah pada percakapan ini tidak dapat diekstraksi karena file yang diterima berukuran 1 byte. Oleh karena itu, dokumen ini menggunakan topik yang terlihat pada judul file dan pengetahuan teknis umum tentang penerapan Naïve Bayes. Detail objek/data spesifik jurnal perlu disesuaikan setelah PDF yang valid tersedia.

## Tujuan sistem
1. Mengelola dataset klasifikasi.
2. Melakukan preprocessing data.
3. Membagi data menjadi data latih dan data uji.
4. Melatih model Naïve Bayes.
5. Melakukan klasifikasi terhadap data baru.
6. Menampilkan hasil klasifikasi dan metrik evaluasi.

## Alur utama
Upload/masukkan data → validasi → preprocessing → pembagian data → training Naïve Bayes → pengujian → evaluasi → klasifikasi data baru → tampilkan hasil.
